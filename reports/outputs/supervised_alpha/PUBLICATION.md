# Supervised Alpha Publication Boundary

This GitHub directory publishes aggregate model diagnostics, validation and
legacy-OOS summaries, model-family comparisons, calibration metrics, plots and
the prospective evidence schedule.

Security-level prediction panels, optimiser inputs, realised-outcome panels,
model binaries, checkpoints and the full internal checksum set stay local.
Those files may contain licensed-derived values and are not required to read
the public research conclusion.

The publication-safe stock list is
[`recommendation_snapshot.csv`](../../presentations/wolf_investment_principal/recommendation_snapshot.csv).
It separates the governed 20-name target from the 20-name regional challenger
and a six-name supervised research watchlist; both challenger groups are
explicitly non-executable. The presentation manifest records SHA-256 hashes for
the restricted local inputs without publishing their paths or contents.
